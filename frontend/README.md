# Market AI Tracker — Frontend

React SPA for the Market AI Tracker platform (see the [project README](../README.md) for full documentation).

```bash
npm install
npm start     # dev server → http://localhost:3000
npm run build # production build → build/
npm test      # unit tests
```

Configure the backend URL in `.env` (see `.env.example`):

```
REACT_APP_API_URL=https://market-ai-tracker.onrender.com
```

Stack: React 19, Axios, ApexCharts, Chart.js (Create React App).
